# VLAD Çekirdeği Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dosya tabanlı bilgi tabanı, `vlad` CLI, görev devri (worktree + görünür terminal), global session raporlama hook'u ve VLAD/çalışan skill'leriyle çalışan bir VLAD çekirdeği kurmak.

**Architecture:** `src/` bir TypeScript kütüphanesidir (kb, tasks, scan, git, launcher, inbox, hooks); `src/cli.ts` bunun üstünde ince bir `commander` sarmalayıcısıdır. Tüm durum `kb/` altındaki YAML-frontmatter markdown ve JSON dosyalarındadır ve her yazma JSON Schema ile doğrulanır. Claude Code entegrasyonu `CLAUDE.md`, `.claude/skills/*` ve hook'lar üzerindendir.

**Tech Stack:** Node 22, TypeScript (ESM, `tsc` → `dist/`), `commander`, `yaml`, `ajv` + `ajv-formats`, `vitest`.

**Spec:** `docs/superpowers/specs/2026-10-15-vlad-core-design.md`

## Global Constraints

- Repo kökü `C:\dev\vlad`; kod içinde VLAD kökü `getVladHome()` ile çözülür: `process.env.VLAD_HOME` varsa o, yoksa derlenmiş dosyadan iki üst klasör (`dist/<x>/..` → repo kökü). Testler her zaman `VLAD_HOME`'u geçici klasöre ayarlar.
- Config varsayılanları (spec §4 aynen): `roots: ["C:\\dev"]`, `ignore: ["*-wt","node_modules","vlad"]`, `defaultAutonomy: "commit"`, `staleAfterHours: 6`, `launcher: "auto"`, `worktreeDir: "{repo}-wt"`, `projects: {}`.
- Görev ID biçimi `T<YYYYMMDD>-<NN>` (NN iki haneli, gün içinde 01'den başlar). Branch `vlad/<id>`. Worktree `<worktreeDir>\<id>`.
- Görev durumları ve geçiş tablosu spec §5.2'deki tablonun aynısıdır.
- Hook: LLM çağrısı yok; her git komutu 3000 ms zaman aşımı; `user_message_count < 2` ise kayıt yok; excerpt = son en fazla 6 metin mesajı, her biri 1000 karaktere kırpılır; her durumda `exit 0`.
- `kb/inbox/`, `kb/logs/`, `dist/`, `node_modules/` gitignore'da. `.gitattributes`: `* text=auto eol=lf`.
- Tüm CLI komutları `--json` destekler: başarıda stdout'a JSON, hatada stderr'e `{"error": "...", "details": [...]}` ve çıkış kodu 1.
- Dışa etki (push/PR/merge) için CLI komutu yazılmaz.
- Tarihler ISO 8601, yerel saat dilimi ofsetiyle (`2026-10-15T21:10:00+03:00`). `nowIso()` tek kaynak.

## Review Focus

1. **Boşluklu / Türkçe karakterli yollar** (`C:\dev\my proj`, başlıkta "Oda senkronizasyonu ğüş") — launcher'ın ürettiği PowerShell script'i ve `wt` argümanları bozulmamalı. → Task 5'e test.
2. **Windows yol karşılaştırması** (`c:/dev/watchparty` vs `C:\dev\watchparty\src`) — proje çıkarımı büyük/küçük harf ve ayraçtan bağımsız olmalı. → Task 6'ya test.
3. **Bozuk transcript satırları ve tool_result içerikli user mesajları** — atlanmalı, sayılmamalı; parser çökmemeli. → Task 6'ya test.
4. **Aynı gün eşzamanlı iki `task new`** — aynı ID'yi almamalı (dosya `wx` bayrağıyla oluşturulur, çakışmada bir sonraki numara). → Task 3'e test.
5. **CRLF satır sonlu kb dosyaları** (kullanıcı Windows editöründe düzenlerse) — frontmatter yine okunmalı. → Task 2'ye test.
