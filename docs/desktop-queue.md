# Gömülü kullanım (vlad-desktop) ve desktop kuyruğu

CLAUDE.md'den taşındı (kurulum denetimi T20261116-22); metin aynen korunur.

`vlad task launch <id> --external --json` worktree + branch + güven kaydı + `running`'i aynen yapar ama terminal AÇMAZ; Windows'ta `%TEMP%\vlad\<id>.ps1` (POSIX'te `$TMPDIR/vlad/<id>.sh`) betiğini yazar ve JSON'da `script`, `command` (Windows: `powershell -NoExit -ExecutionPolicy Bypass -File <betik>`; POSIX: `bash <betik>`), `cwd` döner (bulut modunda reddedilir). `vlad task resume <id> --external` aynı alanları devam prompt'lu betikle verir (oturumu sürdürür: kayıtlı `session_id` varsa `claude --resume <id>`; yoksa worktree'deki tek transcript, o da yoksa taze oturum; `--continue` kullanılmaz (F-vlad-097); `--model` korunur). Durumu değiştirmez (`stalled` ise önce `task set <id> running`) ve açık pencereyi kapatmaz: çift çalışan olmasın diye önce `close-window`. `vlad task close-window <id>` görevin çalışan penceresini/süreç ağacını kapatır; durum ve worktree'ye dokunmaz. **Desktop kuyruğu (Windows):** `VLAD_DESKTOP_QUEUE=<mutlak klasör>` (vlad-desktop yalnız ana VLAD sekmesine verir) tanımlı ve klasör varsa `task launch|resume <id>` terminal açmaz, `--external` hazırlığını yapıp `<klasör>\<id>.json` yazar (v2: `{"v":2,"kind":"launch"|"resume","taskId","script","scriptSha256","cwd","createdAt","pid"}`; `scriptSha256` = betik baytlarının küçük harf hex SHA-256'sı, desktop doğrulamadan çalıştırmaz, v1 reddedilir; `%TEMP%\vlad` klasörü miras kapalı, yalnız geçerli kullanıcı + SYSTEM ACL'iyle oluşturulur/düzeltilir, ACL kurulamazsa dış pencereye düşer; `VLAD_TASK_ID` tanımlıysa kuyruk kullanılmaz; çalışan betiği `VLAD_DESKTOP_QUEUE`'yu temizler); JSON'da `method: "desktop-queue"`, `queued`; uygulama Çalışanlar altında gömülü sekme açar. Klasör yok/yazılamazsa uyarıyla dış pencereye düşer; `--external`/`--dry-run`/bulut etkilenmez.
