## Kapanış raporu

### Amaç
medialog v1: anime, dizi, film, kitap için kişisel takip sitesi. Dış API ile arama, listeler, sezon/bölüm veya sayfa ilerlemesi, arkadaşlarla gerçek zamanlı sohbet. Varsayım V1: 10–500 kullanıcı, en çok birkaç düzine eşzamanlı sohbet.

### Kapsam
**v1 içi:** kayıt/giriş (e-posta+parola), oturum, parola sıfırlama; dört türde arama ve detay; listeler (izlenecek/okunacak, izliyorum/okuyorum, izledim/okudum); dizi/anime sezon+bölüm, kitap sayfa ilerlemesi; "sıradaki bölüm" tek tık; 1–10 puan + kısa not; arkadaş isteği/kabul/kaldırma ve gerçek zamanlı sohbet; profil/liste gizliliği (herkese/arkadaşlara/gizli); engelleme ve mesaj şikâyeti (öneri); hesap silme ve JSON dışa aktarma (öneri); dış API önbelleği ve atıf metinleri.
**v2 adayları:** arkadaş aktivite akışı; yeni bölüm/yayın takvimi ve bildirimler; MAL/Letterboxd/Goodreads içe aktarma; istatistikler, özel listeler/etiketler, grup sohbeti, e-posta/push bildirimi, OAuth.
**Kapsam dışı:** oynatma/indirme, forum, herkese açık keşif akışı, mobil yerel uygulama, ücretli plan, yönetici paneli.

### Senaryolar
**Kayıt/giriş:** 1) geçerli kayıt → hesap + oturum, parola düz metin değil. 2) kayıtlı e-postayla kayıt → genel hata, sızıntı yok. 3) art arda yanlış parola → hız sınırı. 4) parola sıfırlama → tek kullanımlık süreli bağlantı.
**Arama/detay:** 5) "Suits" arama → tür filtreli sonuç (başlık, yıl, kapak). 6) dizi detayı → özet, sezon sayısı, sezon başına bölüm; TMDB atfı. 7) dış API hata/429 → önbellek varsa göster, yoksa anlaşılır hata, çökme yok.
**Listeler:** 8) izlenecek'e ekle → tekrar eklemek çift kayıt yapmaz. 9) durum değişimi → tek durumda. 10) durum/tür filtresi. 11) 1–10 puan, ≤500 karakter not; aralık dışı reddedilir.
**İlerleme:** 12) S2 B15 kaydı ve gösterimi. 13) sıradaki bölüm: S2 B16 → S3 B1. 14) son bölümde sıradaki → "izledim" önerir/geçer (Açık soru 5), geçersiz bölüm yok. 15) bilinmeyen sezon/bölüm elle giriş → bilinen aralıkta doğrulanır, veri yoksa uyarıyla serbest. 16) kitap 120/320; toplamdan büyük reddedilir; toplam yoksa yalnız sayfa.
**Arkadaşlık:** 17) istek+kabul → karşılıklı. 18) ret/iptal → ilişki yok, tekrar istek (spam sınırı). 19) kaldırma → sohbet ve arkadaş-özel görünürlük kapanır.
**Sohbet:** 20) çevrimiçi iki arkadaş → ≤2 sn teslim. 21) çevrimdışı → saklanır, okunmamış görünür. 22) arkadaş olmayan → sunucu reddeder. 23) yeniden bağlanma → kaçırılanlar tekrarsız tamamlanır. 24) engellenen → teslim edilmez, arkadaşlık düşer. 25) şikâyet → mesaj ID + bağlamla kayıt. 26) mesaj seli → hız sınırı.
**Gizlilik/veri hakları:** 27) gizli/arkadaşlara/herkese görünürlük (Açık soru 6). 28) yeni hesap varsayılanı "arkadaşlara". 29) hesap silme → veriler silinir, mesajlar silinir/anonimleşir (Açık soru 7), oturumlar kapanır. 30) JSON dışa aktarma yalnız kendi verisi.
**Dış API/önbellek:** 31) aynı içerik tekrarlı istek → dış API'ye tek istek. 32) anahtar eksik/geçersiz → o tür anlaşılır hata, diğerleri çalışır, anahtar sızmaz.

### Sistem etkisi
exposure: internet; tam sistem tasarımı architect'te.
- **Kimlik/kullanıcı verisi:** yavaş tuzlu parola karması; güvenli oturum çerezi; giriş/kayıt/sıfırlamada hız sınırı; hesap sayımı sızdırmama; e-posta doğrulaması (v1 öneri). Mesajlar uçtan uca şifreli değil (TLS + sunucu erişim denetimi).
- **Yetkilendirme:** liste/profil/sohbet her istekte sunucuda sahiplik/arkadaşlık/gizlilik denetimi.
- **KVKK/GDPR:** hesap silme v1; JSON dışa aktarma v1 öneri; aydınlatma metni/gizlilik politikası v1; hukuki yeterlilik hukukçu işi.
- **Dış API ve önbellek:** sunucu tarafı TTL önbellek, tek-uçuş, geri çekilme, bayat veriyle devam; anahtar yalnız sunucuda; dış veri toplu depolanmaz (AniList şartı) — yalnız listedeki içeriğin gerekli alanları + süreli önbellek.
- **Sohbet/kötüye kullanım:** kimlik doğrulamalı kalıcı bağlantı (el sıkışmada oturum, her mesajda arkadaşlık denetimi); bağlantı/kullanıcı hız sınırı; mesaj uzunluk sınırı; XSS kaçışlama; engelleme + şikâyet (moderasyon arayüzü v2); arkadaş isteği günlük sınır.
- **Ölçek:** 10–500 kullanıcı, tek sunucu yeterli olabilir; yatay ölçek v1 hedefi değil.
- **Dışa açık yüzey:** web, kimlik uçları, arama/detay (dış API vekili; SSRF'e karşı beyaz liste), sohbet ucu, herkese açık profiller, e-posta; loglarda parola/token/mesaj yok.
- **Operasyon:** yedekleme/geri yükleme, gizli anahtar yönetimi, bağımlılık güncellemeleri, TLS.

### Fazlar
Çatıdaki tabloyla uyumlu (tasarım → plan → kabul ∥ uygulama → doğrulama ∥ denetim). Plan: yığın önerisi, Sistem tasarımı (internet tam), içerik modeli ve dış kimlik eşlemesi, sohbet topolojisi, önbellek. Kabul: senaryolar 1–32 ve Sistem etkisi hata durumları.

### Kabul kriterleri
- K1: kayıt/giriş, karma parola, hız sınırı, tek kullanımlık sıfırlama (1–4).
- K2: dört türde arama + filtre; dizi detayında sezon/bölüm; TMDB atfı (5, 6).
- K3: dış API hatasında çökme yok, önbellek/anlaşılır hata, türler birbirinden bağımsız (7, 32).
- K4: üç durum arası geçiş, tek kayıt/tek durum, filtre (8–10).
- K5: puan 1–10 tam sayı, not ≤500 (11).
- K6: S/B ilerleme, sıradaki bölüm sezon geçişi, geçersiz S/B reddi (12–15).
- K7: kitap sayfa sınırı (16).
- K8: arkadaşlık akışı; yalnız arkadaşlar sohbet edebilir (17–19, 22).
- K9: ≤2 sn teslim (test ortamında), çevrimdışı saklama, tekrarsız yeniden bağlanma (20, 21, 23).
- K10: engelleme, şikâyet kaydı, mesaj/istek hız sınırı (24–26).
- K11: gizlilik sunucuda; yetkisiz erişim sızdırmaz; varsayılan "arkadaşlara" (27, 28).
- K12: hesap silme ve JSON dışa aktarma (29, 30).
- K13: tekrarlı istekte tek dış istek; anahtar yanıt/loglarda yok (31, 32).
- K14: dış kaynak şartları: TMDB atfı + "onaylı değil", AniList verisi toplu depolanmaz (6, 31; R1'e bağlı).
