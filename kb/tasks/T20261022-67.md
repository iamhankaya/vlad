### Sistem tasarımı

`exposure: local`; `INTERNET` yok. Silme, geniş izin ve kalıcı yok etme nedeniyle güvenlik odaklı.

**Süreç ve veri.** Tek süreç ve aktivite, arka plan işi yok. Snapshot bellekte kalır (probe: 9.234 dosyada tepe PSS ~87 MB). Kalıcı durum yok.

**İzinler.** `MANAGE_EXTERNAL_STORAGE`, `QUERY_ALL_PACKAGES`, `PACKAGE_USAGE_STATS` (`tools:ignore="ProtectedPermissions"`). `READ_MEDIA_*` gerekmez (sonda yalnızca tüm dosyalara erişimle 3.734 MediaStore satırı okudu). `allowBackup=false`, yalnızca `MainActivity` exported. Kullanım erişimi isteğe bağlıdır. Lint'te `QueryAllPackagesPermission` gerekçeli kapatılır, `HardcodedText` hata yapılır.

**Güvenlik incelemesi gerektirenler (silme):** `ProtectionEngine`, `NioPathResolver`, `DeleteConfirmation`, `PermanentDeleteAuthorization`, `DeletionPlanner`, `DeletionExecutor`, `NioPermanentDeleter`, `GuardedDeletionGateway`, `MediaStoreTrashGateway`, `FilePermanentDeleteGateway`. İnceleme faz 72'de (U2-7); `ProtectionEngine` ve `NioPermanentDeleter` faz 70a'da yazıldığı için inceleme kapsamına faz 72'de dahildir.

**Silme güvenliği, dört kat.**
1. Kurallar korumalı yolları `Risk.Protected`, `selectable=false` işaretler.
2. `DeletionPlanner` yeniden `check` eder ve tekilleştirir.
3. `DeletionExecutor` silmeden hemen önce `checkOnDisk` (`realpath`, bağ izlenmez) ve `size`/`mtime` karşılaştırması yapar. Dizin silmelerinde ağaç toplamı da karşılaştırılır (aşağıda). Fark varsa `Skipped(Changed)`.
4. `GuardedDeletionGateway` son kapıda aynı kontrolü tekrarlar ve `auth.planId`'yi öğelerden yeniden hesaplayıp doğrular.

`PermanentDeleteAuthorization` yalnızca tam `SİL` ile `DeleteConfirmation.authorize` tarafından üretilir. `internal` kurucu derleme zamanı korkuluğudur, güvenlik sınırı değildir (bayt kodunda genel olabilir). Asıl sınır `planId` bağıdır: `planId` = öğelerin (`candidateId|path|mode`, sıralı) SHA-256'sı. Yürütücü ve `GuardedDeletionGateway` bunu yeniden hesaplar. Belirteç tek kullanımlıktır (ikinci kullanım `Skipped(NotAuthorized)`). Planda kalıcı öğe yoksa `authorize` `null` döner.

**Dizin silme.**
- `EmptyTreeOnly`: alttan yukarı `Files.delete`, özyinelemeli silme yok; boş olmayan dizinde `Skipped(Changed)`.
- `RecursiveTree` (`.thumbnails`, `Android/media/<paket>`): silmeden önce ağaç dosya sayısı ve boyutu yeniden hesaplanıp `expectedTreeFiles/Bytes` ile karşılaştırılır (dizin `mtime` yalnızca doğrudan çocuk değişiminde değişir). Yürüyüş `walkFileTree`, `NOFOLLOW_LINKS`; bağ görülürse yalnızca bağın kendisi silinir; her dosyada `protection.check`.

**Cihaz gerçeği: sistem çöp kutusu diyaloğu güvenilir kapı değil.** `createTrashRequest` tüm dosyalara erişimle 118–147 ms'de diyalogsuz `RESULT_OK` döndü; sonda yalnızca kendi sahip olduğu test dosyasını denedi. Başka uygulamanın (Galeri, WhatsApp) medyasında davranış doğrulanmadı. Tek güvenilir kapı uygulamanın kendi özet ve "gözden geçirdim" onayıdır.
- `RESULT_OK` başarı sayılmaz: gateway işlemden sonra `IS_TRASHED=1`'i MediaStore'dan doğrular; doğrulanamayan öğe `Failed(NotTrashed)`.
- Çöp uygunluğu beyaz liste: `media_type ∈ {1,2,3}` (PDF `media_type 6` reddedildi: "All requested items must be Media items").
- `createTrashRequest` hepsi-ya-hiç çalışır: gateway `TRASH_BATCH = 100` parçalar, bir parça `IllegalArgumentException` verirse öğe öğe yeniden dener (sabit ve `TransactionTooLarge` davranışı doğrulanmadı).

**Çöp kutusu kapsamı (VLAD varsayılanı, bkz. Açık noktalar).** M9 yalnızca MediaStore'da `is_trashed=1` ile doğrulanmış ve diskte bulunan dosyaları kapsar. Diskte `.trashed-` önekli ama MediaStore karşılığı olmayan dosya kullanıcı dosyasıdır (`Documents/.trashed-1-onemli.pdf` gibi): "çöp" sayılmaz, normal dosya kurallarına (M6/M7/M8) girer, Dikkat ve işaretsizdir.

### Arayüzler

Tek kaynak. Kotlin imzaları; yollar `/` ayraçlı mutlak string; I/O sınırında `Result` veya durum sınıfı; hiçbir arayüz iptal için `CancellationException` fırlatmaz.

```kotlin
// ---- core.model ----
const val SHARED_ROOT = "/storage/emulated/0"
fun interface Clock { fun nowMs(): Long }                         // ana kaynakta System.currentTimeMillis yalnızca core/io/SystemClock.kt

// ---- core.scan ----
enum class EntryKind { File, Dir, Symlink }
data class RawEntry(val name: String, val kind: EntryKind, val sizeBytes: Long, val modifiedEpochMs: Long)
interface ScanFileSystem { fun list(dirPath: String): List<RawEntry>? }       // null = okunamadı/erişilemiyor
data class ScanOptions(val parallelism: Int = 4, val progressEveryEntries: Int = 2048)
class ScanControl { fun cancel(); val isCancelled: Boolean }
data class ScanProgress(val files: Long, val dirs: Long, val bytes: Long, val elapsedMs: Long)
enum class UnreadableReason { NoAccess, IoError, Symlink }
data class UnreadableDir(val path: String, val reason: UnreadableReason, val message: String? = null)
data class DirRecord(val id: Int, val parentId: Int /* kök=-1 */, val name: String, val path: String,
  val totalBytes: Long, val totalFiles: Long, val trashNamedBytes: Long, val unreadable: UnreadableReason?)
data class FileRecord(val dirId: Int, val name: String, val sizeBytes: Long, val modifiedEpochMs: Long)
data class TrashedFile(val path: String, val sizeBytes: Long, val expiresEpochSec: Long, val originalName: String)
sealed interface ScanStatus { object Complete : ScanStatus; data class Partial(val cancelled: Boolean) : ScanStatus }
data class ScanSnapshot(val root: String, val startedAtEpochMs: Long, val finishedAtEpochMs: Long, val status: ScanStatus,
  val dirs: List<DirRecord>, val files: List<FileRecord> /* .trashed- adlı olmayanlar */,
  val trashNamed: List<TrashedFile> /* ad deseni; MediaStore ile doğrulanmadı */,
  val unreadable: List<UnreadableDir>, val totalBytes: Long, val totalFiles: Long, val durationMs: Long)
{ fun pathOf(f: FileRecord): String; fun dir(id: Int): DirRecord }
interface Scanner { suspend fun scan(root: String, options: ScanOptions, control: ScanControl, onProgress: (ScanProgress) -> Unit): ScanSnapshot }
```
Tarayıcı sözleşmesi:
- `totalBytes` = okunan dosyaların `length` toplamı. `.trashed-*` adlı dosyalar dizin toplamlarına dahildir (diskle birebir) ve `trashNamedBytes`'ta ayrıca görünür. `files` ve `trashNamed` ayrık.
- Sembolik bağlı dosya ve dizin sayılmaz (`Symlink` kaydı), girilmez.
- `list()==null` ise dizin kaydı kalır, `NoAccess` işaretlenir (`Android/data`, `Android/obb`).
- Dizin kimlikleri deterministik (yola göre sıralı atanır); sonuç `parallelism`'den bağımsızdır.
- İptalde bekleyen `list()` dönünce `Partial(cancelled=true)` kısmi snapshot döner. İptalden sonra işlenen girdi sayısı en çok `progressEveryEntries × parallelism`.
- Tarama ve ağaç/treemap işlemleri yinelemelidir (5.000 derinlikte çökmez).

### Test stratejisi

Ortam gerçeği: bulut çalışanında Android SDK yok. `:core` saf JVM olduğundan ağ varsa yerelde koşar (S0 kanıtlar); `:app` yalnızca CI'da. Hiçbir rapor CI yeşili olmadan "doğrulandı" demez.

**Seviyeler.** JVM unit (developer, `core/src/test`), sözleşme testleri (soyut sınıf + fake alt sınıfı, S5), kabul (tester, `core/src/acceptance` ve `app/src/test/.../Acc*`), Robolectric ve Roborazzi (`app/src/test`), cihazda elle (kullanıcı).

**Kararsızlık önlemleri.**
- Duvar saati testi yok: iptal testi `FakeScanFileSystem` içinde `CountDownLatch` ile takılan `list()` çağrısı, `cancel()` ve "iptalden sonra işlenen girdi ≤ `progressEveryEntries × parallelism`" yapısal iddiasıyla yapılır.
- Her tarama testinde sert zaman aşımı (`@Rule Timeout` 30 sn ve `withTimeout`).
- Paralel determinizm: `parallelism` 1, 2, 4, 8 ve tohumlu rastgele gecikmelerle ~50 tekrar; `onProgress` monoton.
- Kök kullanıcıyla `setReadable(false)` anlamsız: okunamayan dizin `FakeScanFileSystem`'le, gerçek dosya sistemi testleri `TemporaryFolder` + `toRealPath` ile; atlanan testler (`assumeFalse`) `skipped` olarak sayılır ve taban denetiminde görünür.
- Locale testi (`tr-TR`) `try/finally` ile geri alınır, testler aynı JVM'de paralel koşmaz.

**Fixture ve türetilmiş veri.** Gerçek (`Real*`): fixture JSON ve içindeki satırlar. Türetilmiş (`Derived*`): `DerivedTreeFactory` (üst düzey toplamlar birebir, iç dağılım tohumlu). M1–M8 kuralları gerçek dağılıma güvenmez, her kural için elle yazılmış minimal ağaçlar kullanır (Türkçe, boşluk, `%`, `_`, `\` içeren adlar dahil). `FIXTURE_NOW_MS` `olcum_zamani_epoch`'tan türetilir. Fixture rakamları iddiaları: `appsAndData == 121.348.478.312`, `SystemAndOther == 12.776.953.849`, toplam `512.000.000.000`, `apps.internalDataBytes` (karakterizasyon; bağımsız oracle değişmezlerdir: toplam eşitliği, negatif yok, segment ≥ 0). Türetilmiş özdeşliklerde tolerans: `external.total − taranan` ile `external.appBytes` farkı < %1.

**Ana test kalıpları (ek ayrıntılar).**
- **Hesaplayıcı:** `scanned > used`, `free > total`, `userStats == null`, `externalStats == null`, kısmi tarama, negatif `raw` (`inconsistent`), `Result.failure` yedeği.
- **Koruma (parametrik tablo, her satırda beklenen karar ve `ProtectionReason`):** boş, göreli, `\`, NUL, `..`, `//`, `./`, sondaki `/`, `/storage/emulated/10`, `/sdcard`, `/storage/self/primary`, `/mnt/user/0/primary`, `/data/media/0`, `Android/media/<paket>/../../data`, `Android/media` kendisi, yüklü paketin kök klasörü, `com.whatsappX` (kabul edilmez), `Databases` ve `Backups`, `.thumbnails` bağ olarak, NFD adlar, kökün her ilk düzey klasörü (`Fonts`, `MIUI`), `DCIM/.globalTrash`, `.trash-storage`, `MIUI/debug_log`. Büyük/küçük harf yalnızca string `check`'te; `checkOnDisk` testlerinde temp `sharedRoot`.
