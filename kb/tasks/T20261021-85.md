## Tanım
medialog **ücretsiz canlı ortam hazırlığı** (kullanıcı kararı: Oracle Cloud Always Free ARM VM + DuckDNS alt alan adı + Gmail SMTP). Üç iş:
1. **SMTP e-posta taşıyıcısı:** `MAIL_TRANSPORT=smtp` (mevcut `file | resend` yanına) — `nodemailer` (pin'li sürüm, `npm audit` 0). Ayarlar: `SMTP_HOST` (varsayılan `smtp.gmail.com`), `SMTP_PORT` (465, TLS zorunlu; 587 STARTTLS `requireTLS`), `SMTP_USER`, `SMTP_PASS`. `RenderedMail.headers` (`safeHeaders`, `List-Unsubscribe` vb.) aynen geçirilsin; v3 hata sınıflandırması (geçici/kalıcı) Resend taşıyıcısındaki desenle aynı olsun (yeniden deneme çizelgesi çalışsın). Üretim doğrulaması: `smtp` için dört ayar zorunlu; `MAIL_FROM` adresi `SMTP_USER` ile aynı olmalı (Gmail başka gönderene izin vermez) — değilse başlangıçta açık hata. Gizli değer günlüğe düşmesin (`SMTP_PASS` loglarda maskeli; test). Birim testleri: sahte SMTP sunucusu (`smtp-server` dev bağımlılığı ya da yerel net soketi) ile gönderim, başlıklar, TLS zorunluluğu, hata sınıflandırması.
2. **Dağıtım yapılandırması:**
   - `deploy.yml`: zorunlu sırlar `RESEND_API_KEY` yerine `MAIL_TRANSPORT`'a göre: yeni GitHub *variable* yok — `SMTP_USER` + `SMTP_PASS` sırları varsa `smtp`, yoksa `RESEND_API_KEY` ile `resend` (ikisi de yoksa eksik sır hatası, hangi seçeneklerin olduğunu yazsın). `.env` üretimi buna göre; `::add-mask::` yeni sırlar için de.
   - `docker-compose.yml`: app servisine `MAIL_TRANSPORT`, `SMTP_*` geçişleri.
   - `bootstrap.sh` Oracle Ubuntu imajı uyumu: Oracle imajlarındaki `/etc/iptables/rules.v4` REJECT kuralları 80/443'ü engeller — ufw ile çakışmadan 80/443 açık kalsın (`netfilter-persistent` kurallarını güvenli biçimde düzenle ya da ufw'ye bırak; idempotent); ARM64 (`aarch64`) üzerinde Docker CE ve imaj derlemesi çalışmalı (Dockerfile taban imajları çok mimarili mi kontrol et; gerekiyorsa düzelt). 1 GB altı RAM uyarısı yerine ARM VM'de sorun yok; swap dosyası yoksa 2 GB oluştur (idempotent).
   - `scripts/check-deploy.sh`: smtp yolu için compose/env denetimi.
3. **RUNBOOK §1 baştan, ücretsiz yol için adım adım (Türkçe, ekran adlarıyla):** Oracle Cloud hesabı (Home region seçimi kalıcı; Always Free uygun bölge), VCN + public subnet, Security List'te 80/443 ingress, Ampere A1 VM (2 OCPU/12 GB önerisi; "Out of capacity" çıkarsa başka AD/deneme), SSH açık anahtarı ekleme, public IP (Reserved önerilir); DuckDNS (GitHub ile giriş, alt alan adı, IP; isteğe bağlı sunucuda cron güncelleyici — IP rezerve ise gerekmez); Gmail (2 adımlı doğrulama → Uygulama şifreleri → 16 haneli şifre = `SMTP_PASS`); TMDB; GitHub sırları tablosu (smtp yoluyla); `DEPLOY_KNOWN_HOSTS` için Oracle "Cloud Shell"/konsol bağlantısı yolu; Always Free boşta kalma geri alma politikası notu ve önlemi. Resend yolu "alternatif" olarak kısa kalsın.
